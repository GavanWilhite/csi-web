The Cognitive Security Conference is the premier event for human risk management, AI security, and cognitive warfare professionals. 

 

Hosted by the [Cognitive Security Institute](https://www.cognitivesecurityinstitute.org), this event has become the most highly anticipated conference in the cognitive domain. It brings together a unique blend of security practitioners, researchers, neuroscientists, mentalists, psychologists, con artists, policymakers, and many others who operate in and study cognitive hacking.​
